# Подоконник

Бесплатная программа для Windows 10 и 11: снег, листья и лепестки падают поверх окон и копятся на них, как на настоящем подоконнике. Четыре сезона, живые обои и музыка.

Сайт: https://aleksandrkrasnikov97-dot.github.io/podokonnik/

Скачать: [podokonnik.zip](podokonnik.zip)

Музыка: Kevin MacLeod (incompetech.com), CC BY 4.0. Видео для обоев: авторы Wikimedia Commons.
