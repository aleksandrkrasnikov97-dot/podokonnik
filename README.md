# Подоконник

Бесплатная программа для Windows 10 и 11: снег, листья и лепестки падают поверх окон и копятся на них, как на настоящем подоконнике. Четыре сезона, праздники, кот на подоконнике, живые обои, музыка и радио.

Сайт: https://aleksandrkrasnikov97-dot.github.io/podokonnik/

Скачать: [установщик](Podokonnik-Setup.exe) или [архив без установки](podokonnik.zip)

Музыка: Kevin MacLeod (incompetech.com), CC BY 4.0. Видео для обоев: авторы Wikimedia Commons.


Сцены Wallpaper Engine воспроизводятся движком [WebWallGL](https://github.com/WTStarMark/webwallgl) (MIT).

Каталог обоев: [catalog/catalog.json](catalog/catalog.json) — обои собственного изготовления, CC0.
